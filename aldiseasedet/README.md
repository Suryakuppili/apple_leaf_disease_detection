# Apple Leaf Disease Detection Using Deep Learning

A deep learning-based computer vision project that identifies diseases in apple leaves using image classification. The system compares two convolutional neural network architectures — a **Custom CNN** and **MobileNetV2** — and provides predictions through a web-based interface.

The project uses the PlantVillage Apple Leaf dataset and evaluates both models using accuracy, precision, recall, F1-score, model size, and inference time.

## 1. Project Overview

Apple leaf diseases can affect plant health, fruit quality, and agricultural productivity. Identifying these diseases at an early stage can help farmers and agricultural researchers take appropriate action.

This project develops an image-based apple leaf disease classification system using Deep Learning.

Two models are implemented and compared:

- **Custom CNN:** A convolutional neural network designed and trained specifically for the apple leaf classification task.
- **MobileNetV2:** A lightweight, pretrained convolutional neural network using transfer learning with ImageNet weights.

Users can upload an apple leaf image through the web application and view the predictions generated by both models, including their predicted disease, confidence score, and inference time.

### Main Features

- Classification of four apple leaf conditions.
- Two independently trained Deep Learning models.
- Transfer learning using MobileNetV2.
- Model performance evaluation on an independent test set.
- Side-by-side prediction comparison.
- Image upload through a web interface.
- Confidence score and inference-time display.

---

## 2. Problem Statement

Apple trees (*Malus domestica*) are affected by several foliar diseases, including Apple Scab, Black Rot, and Cedar Apple Rust.

Traditional disease identification often depends on manual inspection. This can be time-consuming and may require agricultural expertise.

The objective of this project is to develop an automated image classification system that can identify common apple leaf diseases using Deep Learning.

The project also compares two different CNN architectures to understand their differences in classification performance, computational requirements, model size, and inference speed.

**Project scope:** This implementation focuses on four-class image classification and comparative evaluation of two Deep Learning models. It does not currently implement disease severity estimation, lesion segmentation, treatment recommendations, or agentic AI.

## 4. Target Classes

The project identifies four apple leaf conditions.

| Dataset Label | Disease / Condition |
|---|---|
| `Apple___Apple_scab` | Apple Scab |
| `Apple___Black_rot` | Black Rot |
| `Apple___Cedar_apple_rust` | Cedar Apple Rust |
| `Apple___healthy` | Healthy |

### 1. Apple Scab

<em>Venturia inaequalis</em>

A fungal disease that commonly produces olive-green, brown, or dark lesions on apple leaves.

### 2. Black Rot

<em>Botryosphaeria obtusa</em>

A fungal disease associated with circular brown lesions that may develop dark centers and surrounding discoloration.

### 3. Cedar Apple Rust

<em>Gymnosporangium juniperi-virginianae</em>

A fungal disease that produces characteristic yellow-orange spots on apple leaves.

### 4. Healthy

Leaves that do not belong to any of the three disease categories in the dataset.

## 5. Deep Learning Models

Two different CNN architectures are implemented for comparative analysis.

### Model 1: Custom CNN

The Custom CNN is designed specifically for the apple leaf disease classification task.

It learns visual features directly from the training images through convolutional and pooling operations.

The model is trained from scratch using the prepared apple leaf dataset.

**Key characteristics:**

- Custom convolutional neural network architecture.
- Learns image features during training.
- Four-class output layer.
- Softmax-based class probability prediction.
- Relatively small model size.

**Saved checkpoint:**

`models/dl/custom_cnn.pt`

### Model 2: MobileNetV2

MobileNetV2 is a lightweight CNN architecture originally developed for efficient image recognition.

This project uses transfer learning with pretrained ImageNet weights.

The original classification layer is replaced with a new output layer containing four classes.

**Key characteristics:**

- Pretrained ImageNet weights.
- Transfer learning for apple leaf classification.
- Modified final classification layer.
- Efficient CNN architecture.
- Softmax-based class probability prediction.

**Saved checkpoint:**

`models/dl/mobilenet_v2.pt`

### Why Compare These Models?

The comparison helps evaluate the trade-off between classification performance and computational efficiency.

| Comparison Factor | Custom CNN | MobileNetV2 |
|---|---|---|
| Training approach | Trained from scratch | Transfer learning |
| Architecture | Custom CNN | Pretrained CNN |
| Classification classes | 4 | 4 |
| Main advantage | Smaller model | Higher test performance in this experiment |
| Model size | Smaller | Larger |

## 6. Image Preprocessing

Both models receive images in a standardized format.

The preprocessing pipeline includes:

1. **Image loading:** Read the uploaded image.
2. **Color conversion:** Convert the image into RGB format.
3. **Resizing:** Resize the image to 224 × 224 pixels.
4. **Tensor conversion:** Convert the image into a PyTorch tensor.
5. **Normalization:** Normalize using ImageNet mean and standard deviation.

### Normalization Parameters

Mean:

`[0.485, 0.456, 0.406]`

Standard deviation:

`[0.229, 0.224, 0.225]`

The preprocessing used during single-image prediction is designed to match the evaluation preprocessing.

This ensures that uploaded images are provided to the models in the expected input format.

## 8. Model Evaluation and Results

Both trained models are evaluated using the independent test dataset containing 318 images.

The evaluation considers classification performance as well as computational efficiency.

### Evaluation Metrics

- **Accuracy:** Percentage of correctly classified test images.
- **Precision:** Measures how many positive predictions are correct.
- **Recall:** Measures how many actual samples are correctly identified.
- **Macro F1-score:** Harmonic mean of precision and recall, averaged equally across all classes.
- **Inference Time:** Average time required to process an image.
- **Model Size:** Storage size of the saved model checkpoint.

### Experimental Results

The following results were obtained from the project's test evaluation.

| Metric | Custom CNN | MobileNetV2 |
|---|---:|---:|
| Accuracy | 98.11% | 100.00% |
| Macro Precision | 98.12% | 100.00% |
| Macro Recall | 97.85% | 100.00% |
| Macro F1-score | 97.97% | 100.00% |
| Average inference time | 12.3 ms | 21.5 ms |
| Model size | 1.10 MB | 25.86 MB |

### Result Analysis

**Custom CNN**

- Achieved 98.11% test accuracy.
- Has a significantly smaller model size.
- Demonstrated faster average inference in the recorded evaluation.

**MobileNetV2**

- Achieved 100% accuracy on the 318-image test set.
- Achieved 100% macro precision, recall, and F1-score on this test set.
- Requires more storage space than the Custom CNN.
- Had a higher average inference time in the recorded evaluation.

### Overall Observation

MobileNetV2 achieved the highest classification performance in this experiment, while the Custom CNN demonstrated advantages in model size and inference speed.

These results illustrate the trade-off between model complexity and computational efficiency.

**Important:** The reported 100% test accuracy applies only to this particular held-out PlantVillage test set. It does not establish guaranteed accuracy on real-world photographs captured under different lighting, backgrounds, and environmental conditions.

## 9. Single-Image Prediction

The project supports prediction on individual apple leaf images.

The prediction script loads the trained MobileNetV2 checkpoint and processes an input image.

### Prediction Command

```bash
python -m src.dl_predict --image "path/to/apple_leaf.jpg"
```

### Prediction Output

The script displays:

- Predicted disease class.
- Confidence score.
- Probability for each of the four classes.

Example:

```text
Predicted Disease: Apple___Black_rot
Confidence: 90.36%

Class Probabilities:
Apple___Apple_scab: 6.53%
Apple___Black_rot: 90.36%
Apple___Cedar_apple_rust: 3.11%
Apple___healthy: 0.00%
```

The confidence score represents the model's predicted probability for its selected class. It should not be interpreted as a guarantee of diagnostic correctness.

## 10. Web Application

The project includes a web interface that allows users to upload apple leaf images and view classification results.

The current application is implemented using Streamlit.

### Main Features

- Upload an apple leaf image in JPG, JPEG, or PNG format.
- Preview the uploaded image.
- Run predictions using both trained models.
- Display the predicted disease from each model.
- Display the confidence score for each prediction.
- Display the inference time for each model.
- Compare the predictions generated by the two models.

The application uses the saved model checkpoints and does not retrain the models when a user uploads an image.

## 15. Limitations

Although the models achieved strong performance on the PlantVillage test dataset, several limitations remain.

1. **Controlled Dataset Conditions:** PlantVillage images generally have controlled backgrounds and lighting. Performance may differ on real-world orchard photographs.

2. **Limited Disease Categories:** The current implementation recognizes only three disease categories and one healthy category.

3. **Dataset Size:** The project uses 3,171 images, which limits the variety of leaf appearances and environmental conditions represented.

4. **Confidence Interpretation:** Softmax confidence scores do not necessarily represent calibrated probabilities of real-world diagnostic correctness.

5. **Computational Requirements:** The two models have different storage and inference requirements. Performance may vary depending on the hardware used.

6. **No Severity Estimation:** The current implementation identifies the disease category but does not calculate the percentage of infected leaf area.

7. **No Treatment Recommendation:** The system is a classification project and does not provide verified agricultural treatment advice.

## Conclusion

This project demonstrates the application of Deep Learning to apple leaf disease classification.

By implementing and evaluating a Custom CNN and MobileNetV2, the project compares a model trained from scratch with a transfer-learning-based architecture.

The experimental results show that MobileNetV2 achieved higher classification performance on the selected test dataset, while the Custom CNN offered lower model size and faster inference.

The final system combines dataset preparation, model training, evaluation, single-image prediction, and a web-based interface into one practical Deep Learning project.
